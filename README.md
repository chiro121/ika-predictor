# 🦑 宝来丸 イカメタル釣果予測ツール

宝来丸のイカメタル釣果データをCSVから読み込み、  
過去の釣果傾向から「次回どのくらい釣れそうか」を予測するPythonアプリです。

## 起動
```text
pip install pandas numpy
python main.py
```

---

## 📌 このツールでできること

### 🔮 釣果予測

予測日の条件を入力すると、過去の似た条件の釣果を分析して、

- 20杯以上釣れる確率
- 30杯以上釣れる確率
- 40杯以上釣れる確率
- 予想釣果レンジ
- 信頼度
- 似ている過去の釣行データ

を表示します。

### 📊 条件ランキング

過去のデータから、

> 潮回り × 月齢帯 × 潮の速さ × 天気

の組み合わせごとに、20杯以上釣れた割合を集計。

データ件数が少ない条件が「100%」になってしまう問題を避けるため、少数データには補正を行っています。

---

## 🌙 月齢

月齢は地域によって変わるものではないため、予測時に手入力する必要がないよう、予測日から自動計算する仕様です。

月齢は以下の4つの月齢帯に分類して分析します。

- 新月〜上弦
- 上弦〜満月
- 満月〜下弦
- 下弦〜新月

---

## ☀️ 天気の分析

天気は単純に「晴」「曇」「雨」が一致するかだけではなく、

**前日 → 当日の天気変化**

も考慮します。

例えば、

```text
晴 → 晴
曇 → 晴
雨 → 晴
晴 → 雨
